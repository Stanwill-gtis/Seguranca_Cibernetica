# 1° Laboratórios de Redes:

Este diretório contém os arquivos das aulas práticas, onde abordamos conceitos fundamentais de redes de computadores, utilizando o **Cisco Packet Tracer** para simulação.

## Estrutura dos Arquivos

* **Aula 7 - Laboratório DHCP:**
  Documento em PDF contendo o roteiro e a resolução da prática sobre configuração de **DHCP** em um roteador sem fio, com atribuição automática de endereços IP para hosts.

* **Aula 8 - Laboratório NAT:**
  Arquivo de simulação do **Packet Tracer** referente à configuração de **NAT (Network Address Translation)** em um roteador, permitindo a comunicação entre redes privadas e públicas.

* **Aula 9 - Laboratório - Identificar endereços MAC e IP:**
  Arquivo de simulação do **Packet Tracer** para identificação e análise de **endereços MAC e IP**, reforçando conceitos de endereçamento em redes locais.

## Pré-requisitos

* **Cisco Packet Tracer** (versão 8.x ou superior recomendada).
* Leitor de PDF para visualizar os roteiros.

## Como Utilizar

1. Abra o arquivo `.pka` no **Cisco Packet Tracer**.
2. Siga os passos descritos no PDF (quando aplicável).
3. Teste a configuração utilizando os PCs e roteadores virtuais (ping, ipconfig, etc.).

## Conteúdo Abordado

* **Aula 7 – DHCP**: Configuração de servidor DHCP em roteador wireless, alteração de faixas de IP, testes de conectividade.
* **Aula 8 – NAT**: Tradução de endereços de rede, conectividade entre LAN e Internet.
* **Aula 9 – MAC/IP**: Identificação prática de endereços físicos (MAC) e lógicos (IP).

## Observações

* Os arquivos `.pka` devem ser abertos diretamente no **Cisco Packet Tracer**.
* O PDF serve como guia passo a passo para execução e validação dos laboratórios.
* Recomendado salvar cópias após realizar modificações nos cenários.
